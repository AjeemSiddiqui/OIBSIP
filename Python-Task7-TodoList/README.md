# To-Do List App

## Description
A simple command-line To-Do List application developed using Python. This program allows users to add, view, and delete tasks easily.

## Features
- Add new tasks
- View all tasks
- Delete completed tasks
- Simple and user-friendly interface
- Menu-driven program

## Technologies Used
- Python

## How to Run

```bash
python todo_list.py
```

## Example Menu

```text
===== TO-DO LIST =====
1. Add Task
2. View Tasks
3. Delete Task
4. Exit
```
