# Expense Tracker

## Description
A simple Expense Tracker application developed using Python. This program helps users manage their income and expenses while keeping track of their current balance and transaction history.

## Features
- Add Income
- Add Expenses
- View Current Balance
- View Transaction History
- Simple Menu-Driven Interface

## Technologies Used
- Python

## How to Run

```bash
python expense_tracker.py
```

## Example Menu

```text
===== Expense Tracker =====
1. Add Income
2. Add Expense
3. View Balance
4. View History
5. Exit
```

## Sample Output
